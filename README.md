# RentNear

Zero-security-deposit rental discovery for family homes, flats, rooms, PGs and studios.

## Starter deployment
This repository is being set up as a React + Vite app for GitHub Pages. The first build is a UI prototype with sample listings. Do not treat sample listings or illustrative verification badges as real properties.

## Features
- Search by locality and property type
- Filter by rent and furnishing
- Zero security-deposit policy
- Owner listing form (demo-only local storage)
- Responsive rental cards and ad placeholder

## Limitations
No shared database, production authentication, true photo upload, map provider integration, live owner enquiries, or AdSense integration is enabled yet. GitHub Pages hosts the static frontend only.
